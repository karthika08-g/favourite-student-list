# 🎓 Favourite Student List

A React-based web application to manage student details and maintain a list of favourite students.

## 🚀 Features

- View a list of students.
- Search students by name or roll number.
- Filter students by department.
- Add students to favourites.
- Remove students from favourites.
- Prevent duplicate favourite entries.
- View favourite students on a separate page.
- Navigate between pages using React Router.
- Manage application data using React Context API.
- Responsive and user-friendly interface.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Context API
- Vite

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/karthika08-g/favourite-student-list.git
```

2. Navigate to the project folder:

```bash
cd favourite-student-list
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.
